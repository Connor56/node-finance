# Node Finance

## What is it?

Node Finance is a personal finance application to help you track cash flow and wealth. It has the following features:

- It takes your income, outgoings, and capital and displays them in a visual graph.
- It lets you upload JSON data in the node-finance format to quickly visualise your financial situation.
- It lets you delete individual incomes, outgoings, and capital.
- To help you plan for the future, it lets you create speculative incomes and outgoings with percentages attached to them.
- It lets you group together related incomes, outgoings, or capital, decluttering and simplifying the graph.
- It lets you save and load your data, all of which is stored locally in your browser.
- It costs NOTHING and will be useable in its current state forever.

## Who is it for?

This application is for anyone who wants a simple, self-hosted tool to manage their personal finances without relying on third-party services that may compromise privacy. But more specifically, here are some groups who might find it interesting:

- People who use the `You Need a Budget` (YNAB) app, and don't like the standard reflection tools provided by YNAB (This is me). This tool can help you turn your pre-existing YNAB data into a visual graph that helps you see your current financial situation clearly, and plan for the future. I find this visualisation much more useful than what YNAB currently offers.

## What can you get out of it?

By using Node Finance, you can gain a better understanding of where your money goes. It helps you visualize your financial data, identify trends, and make more informed financial decisions.

## Open Source for Learning

The source code for Node Finance is deliberately public. Firstly, for your security. Secondly, as an educational resource for developers building web applications with standard browser tools (no frameworks). I encourage your to explore and comment on the code to understand the architecture, patterns, and implementation details.
